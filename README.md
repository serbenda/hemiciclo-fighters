# Hemiciclo Fighters

Juego de lucha 2D estilo recreativa de los 90 con políticos ficticios. HTML + JS, sin dependencias.

**Jugar:** https://serbenda.github.io/hemiciclo-fighters/

## Candidatos

| Personaje | Especial |
|---|---|
| Don Promesas | Promesa Electoral |
| Ministra Recortes | Tijeretazo |
| El Barón | Puerta Giratoria |
| Doña Encuesta | Cocina de Encuestas |

Todos comparten la super: **Moción de Censura**, que se carga llenando la barra de Popularidad.

## Controles

| Acción | Jugador 1 | Jugador 2 |
|---|---|---|
| Moverse | A / D | ← / → |
| Saltar | W | ↑ |
| Agacharse | S | ↓ |
| Puño | F | K |
| Patada | G | L |
| Especial | H | O |
| Super | J | P |

- Mantén hacia atrás para cubrirte.
- Agachado + patada derriba al rival.
- Contra la CPU también valen las flechas y Z / X / C / V.
- En móvil aparecen controles táctiles.

## Ejecutar en local

Abre `index.html` en el navegador. No necesita servidor ni instalación.
